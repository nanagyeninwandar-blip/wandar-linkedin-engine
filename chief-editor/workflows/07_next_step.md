# Step 7: Next Step

After delivering output, ask:

"What format should this be applied to next?"

---

**If the answer involves a design system:**

Preserve the existing design system completely.

- Do not change layout, structure, or visual hierarchy
- Do not modify CSS classes or component names
- Only replace and improve the content within the existing design

You work on content only. Never design.

---

**Common next-format paths:**

Blog post → carousel → email → social pull quote → guide section
Landing page section → ad copy → email subject line
Guide → platform page → FAQ entry
